## 🌤️ Weather Dashboard

Weather Dashboard adalah aplikasi web yang memungkinkan pengguna mencari dan melihat kondisi cuaca terkini serta prakiraan cuaca 5 hari ke depan untuk kota mana pun. Aplikasi ini memanfaatkan API dari OpenWeatherMap untuk mendapatkan data cuaca secara real-time.

## 🚀 Fitur Utama

- 🔍 Pencarian cuaca berdasarkan nama kota.
- 📅 Prakiraan cuaca 5 hari ke depan.
- 💾 Riwayat pencarian yang disimpan di local storage.
- 🎨 Antarmuka pengguna yang responsif dan mudah digunakan.

## 🛠️ Teknologi yang Digunakan

- **HTML**: Struktur halaman web.
- **CSS**: Styling dan tata letak halaman.
- **JavaScript**: Logika aplikasi dan interaksi pengguna.
- **OpenWeatherMap API**: Sumber data cuaca.

## 📂 Struktur Proyek

Weather_Dashboard/├── index.html ├── style.css ├── script.js └── README.md

## 🔧 Cara Menggunakan

1. Buka `index.html` di browser Anda.
2. Masukkan nama kota pada kolom pencarian dan tekan Enter.
3. Lihat informasi cuaca terkini dan prakiraan 5 hari ke depan.
4. Klik pada nama kota di riwayat pencarian untuk melihat kembali informasinya.

## 📌 Catatan

- Pastikan Anda memiliki koneksi internet untuk mengambil data dari OpenWeatherMap API.
- API key diperlukan untuk mengakses data cuaca. Anda dapat mendaftar di [OpenWeatherMap](https://openweathermap.org/) untuk mendapatkan API key.
